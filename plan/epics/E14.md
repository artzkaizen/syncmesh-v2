## Goal

Ship state, not history: a joining device receives the rows it is entitled to and can show, adopts cursors only when the snapshot is complete, and gets one signature per chunk instead of per event over a slow radio. Then put it on the wire.

> epic needs — `Interest` and sender-side filtering — with the IVM it used to carry retired and
> the relay's row path moved to E27. The dependency stands, and is now a smaller one.

## Tasks

- [x] `engine.snapshot({ interest? })` / `engine.installSnapshot()` — one pair rather than four: an interest is what makes a snapshot scoped, and the snapshot records the slice it is complete for, so `snapshotFor`/`installScopedSnapshot` would have been the same code under two more names. Merges by stamp through the ordinary field-level merge, one fold batch however many rows, tombstones included, and the coverage adopted **only** after every row is durable
- [x] Compact snapshot codec (dictionaries + stamp dedup) — `encodeSnapshotRows` / `decodeSnapshotRows` in `@syncmesh/wire`. Peers, tables-with-columns and partitions each get one dictionary and are named by index; a cell sitting at its row's write stamp carries no stamp at all, which is the ordinary case. Lossless: what goes in comes out, tombstones and moved cells included
- [x] Per-author feed chains in `@syncmesh/wire`: `advanceFeed` folds an author's event cores into `head(n) = sha256(head(n-1) ‖ core(n))`, `certifyFeed` signs only the head, and `chunkFrom` / `verifyChunk` carry and check a run of any length for **one** Ed25519 verification. A run must start exactly where the receiver's chain does — the gap is what the chain exists to notice
- [x] `chunkSince` / `receiveChunk` at the engine: a chain tracked per author as events fold — boot replay included, so a device that restarts with history recomputes its heads rather than losing them — and stored events turned into runs. `receiveChunk` verifies once and then hands the events to the ordinary `receiveBatch`: the signature is what a run saves, and every other rung of the ladder still runs. The engine holds no key, so the certificate comes from where the key is (`rememberCertificate`)
- [x] Wire: `snap-req → snap-manifest → snap-chunk* → snap-ack` under one session tag with a sub-kind, so the exchange stays inside a tag it owns. The coverage travels on the manifest and is adopted only once every page it named has arrived; a page that never came is named by index in the ack and sent again. `bridge.requestSnapshot(interest?)` asks, `onSnapshot` reports what landed — as **provisional**, because a snapshot carries no per-event signatures
- [x] `join` carries an interest; relay filters catch-up and live fan-out by it — shipped with E13
- [ ] `bench/join` — the four strategies, reproduced over the wire

- [x] Source priority for a join: `Transport.priority` (0 storage, 1 relay, 2 radio) and `Transport.caughtUp()`, gathered by `mesh.settled()` — the question an app answers before it draws an empty state. Sources are awaited **sequentially, nearest first**, so a radio holding nothing never resolves ahead of the relay that holds everything; a medium with no end-of-catch-up to report is settled once it is ready, and a relay that never speaks force-resolves rather than wedging the mesh

## Watch out

- A snapshot must be COMPLETE for its scope or the missing rows are missing forever — adopting cursors is the saving and the risk.
- A backfill must never resurrect a tombstoned row.

## Tests

- [x] `engine/snapshot.test`: rows and the coverage they stand for; tombstones travel and are not resurrected, whichever order a stale snapshot arrives in; an interest narrows it and the snapshot says which slice it is complete for; one fold batch for fifty rows; installing twice is installing once and an older snapshot never lowers coverage; **snapshot + live events ≡ full replay**, compared by digest.
- [x] `wire/feed.test`: one signature carries two hundred events; a receiver continues from where it is and the heads agree, so the chain is the events and not the runs; changing, dropping or reordering any event breaks it; an impostor's certificate over the same head is refused; a run that skips ahead is refused rather than guessed at.
- [x] `engine/feed.test`: two hundred events for one verification; the engine's computed chain is the author's own, so a run built from it verifies; `chunkSince` serves nothing without a certificate, and only what the receiver is missing with one; a reordered run and a run that skips ahead both fold nothing; one signature is not permission — a denied event in a verified run is still quarantined.
- [x] `wire/snapshot-codec.test`: a round trip keeps cells, stamps, partition and tombstones; a cell a later write moved keeps its own stamp while the rest share the row's; the dictionaries beat a record at a time by more than 3×; an out-of-range index and a version this build does not know are refused rather than half-read.
- [x] `transport/join.test`: over a link that carries no events at all, a joiner ends up holding rows it never replayed and the coverage behind them; a snapshot is paged; a dropped page is re-requested by index and the join still completes; a lost **last** page installs nothing and adopts no coverage; an interest narrows the join and the report says which slice it was complete for; an empty snapshot is a completed join, not a stalled one.
- [x] `client/settled.test`: nearest first, and the far source finishing first changes nothing; a source that cannot say when it is done is settled once it is ready.
- [ ] The rest of RFC-0019's tests-to-pin: different interests converge once they meet.
