## Goal

A repository you can build in for months: tests run, types check, CI is green, the wire oracle is wired up, and the rules from `README.md` are enforced by tooling rather than memory.

## Decisions needed

D01 language and layout · D02 error model

## Tasks

- [ ] Choose runtime and layout (D01); `package.json`, `tsconfig` (strict, `exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`)
- [ ] Test runner and a `bun test` (or equivalent) that runs in under a minute
- [ ] CI: install, typecheck, test on push and PR
- [ ] Lint: no floating promises, and — once the `Result` type exists — no floating results
- [ ] `conformance/` directory with `research/wire-vectors.json` copied in, and a test harness that can run vectors against a codec that does not exist yet (red)
- [ ] `Result` / tagged error primitive chosen or written (D02)
- [ ] A `bench/` directory with one benchmark that runs (even a trivial one) so the habit exists

- [ ] Acceptance suites as a shipped module: `runTransportTests(setup)` and `runDriverTests(setup)` — a three-peer sync suite and a storage round-trip suite that every adapter must pass (automerge-repo's `runNetworkAdapterTests`). Write the harness now, red, so E04 and E11 fill it
- [ ] A metrics/telemetry seam from day one — one discriminated union, every subsystem emits `{ type, sizes, durationMillis }`, re-emitted by the top object (D17). Cheaper now than retrofitted

## Watch out

- `bun:sqlite` at the top level of any module that a browser or Node consumer can import will break them — behind a port from the first commit.
- Decide D02 before the first `Result` is returned anywhere; it cannot be changed later.

## Tests

- The vector harness fails red against an empty codec — proves the oracle is wired.
- CI runs the suite on a fresh clone.

## Done when

A fresh clone passes CI in one command, and the wire vectors are failing for the right reason.
