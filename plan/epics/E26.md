## Goal

**Superseded by D25 — this epic is closed and its code deleted.**

`t.counter()` and `t.set()` are gone. One column type per data type, with `merge` as its option
(`lww | max | min`); lists, tags and memberships are tables, where a row per element already
has its own identity, its own tombstone and its own compaction — all of which the `set` kind
reimplemented one layer down and never finished.

Nothing in `plan/use-cases.md` asked for a counter, a set or collaborative text. D22-A means an
unrecognised change kind is now parked rather than refused, so a later build can add a lattice
back and older builds will hold its events rather than drop them: deleting is no longer one-way.

Deleted with it: `CellChange`, `applyCellChange`, `counter.ts`, `set.ts`, the kernel's set
compaction, `crdt-codec.ts`, wire tags 3–5, and `conformance/cell-vectors.json`. One change model
on the wire, three tags instead of six.
