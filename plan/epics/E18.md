## Goal

Old and new app versions coexist on one mesh: contiguous cursors so a hole is visible, a knob for unknown events, quarantine with retry after upgrade, and an additive-only rule instead of a migration system.

## Decisions needed

D13

## Tasks

- [ ] Contiguous cursors `{ contiguous, ahead }` per author replacing MAX; `cursors()` still returns the contiguous number; relay follows
- [ ] `unknownHandling: "warn" | "ignore" | "fail"` on `createMesh`
- [ ] Quarantine store — verbatim bytes + typed reason in their own table; `engine.quarantine()`, `retryQuarantined()`, `onQuarantine()`; bounded per reason with loud eviction
- [ ] The additive-only rule, documented and lint-checked; renames are adds
- [ ] Then: `onConflict("counter")` / `("set")` — one new change kind carrying a delta, kernel merge, a frozen vector; old peers park it

## Watch out

- MAX cursors hide a dropped event forever. Contiguous first, or nothing else here works.
- A parked event must not advance the cursor past itself.

## Tests

- A newer peer emits an unknown change kind; the older parks it, does not advance, admits it after `retryQuarantined()`, converges. Property: a mid-stream version bump converges to the same state as an all-current schedule. Fuzz: sustained forged load never grows quarantine past the cap.

## Done when

Two app versions on one mesh converge, and the older one shows the newer's rows minus the columns it cannot read.
