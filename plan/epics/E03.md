## Goal

A byte-exact encoding of events and grants, signed so that any relay or peer can re-forward bytes it did not author, verified before anything touches state. A Rust or Swift port is compatible when it reproduces `wire-vectors.json` byte for byte.

## Decisions needed

D03 wire

## Tasks

- [ ] Canonical CBOR `Writer`/`Reader`: integer keys ascending, object keys sorted, absent optionals *skipped*, safe ints as ints else f64, byte strings for keys
- [ ] `encodeEventCore` / `decodeEventCore` — keys `0 v · 1 peerId(32 raw bytes) · 2 seq · 3 hlc · 5 procedure · 6 partition? · 7 changes[{0 kind,1 table,2 key,3 data}]`; decoder refuses `v ≠ 1`; unknown map keys ignored
- [ ] Identity: Ed25519 keypair from a seed; `peerId` = hex public key; `sign`/`verify`
- [ ] Envelope `[core, sig]`; `decodeAndVerify(wire)` returns a value, never throws
- [ ] `GrantCore` codec (keys `0..6`) sharing the envelope
- [ ] `hexToBytes`/`bytesToHex`
- [ ] Vector harness green; a script that (re)generates vectors from a fixed seed, run only when the wire deliberately changes
- [ ] Fuzz: 500 garbage frames, 300 bit-flips/truncations of valid events, grant garbage — never a throw, never a state mutation, pristine bytes still apply afterwards

## Watch out

- The signature covers the *received* bytes. Never re-encode before verifying; never 'normalise' on the way in.
- `null` and *absent* are different bytes. A pre-partition event must keep its frozen shape; a partitioned one adds key 6.
- Floats: `Number.isSafeInteger` → int, else f64. A 1.0 encoded as float changes the signature.

## Tests

Every vector reproduces byte-for-byte; the fuzz lane cannot poison dedup or throw.
