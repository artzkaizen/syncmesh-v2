## Goal

Permissions as a JSON AST evaluated identically at the call site, on the local write path, and on every receiving peer — so a hacked client can sign whatever it likes and the mesh refuses it. Combinators bound to the table so a typo is a compile error.

## Decisions needed

D06 (bound combinators)

## Tasks

- [x] AST nodes: `allow deny role owner rowIs patchOnly any all not`; `AllowBlock` with `$default` required; `resolveAllow` (`op ?? write ?? $default`)
- [x] Pure `evaluate(node, { grant, row, patch, roles })`; roles senior→junior; `role(x)` = x or more senior
- [x] Bound combinators: `allow: ({ role, owner, rowIs, patchOnly, any, all, not }) => …` typed to the table's roles (nearest ancestor kind declaring them) and columns
- [x] `PolicyDoc` JSON round-trip test — must be byte-stable, it will sync as data
- [x] `createValidator(schema, grantFor | null, { isAuthority })` — order: grant → device match → partition rules → **schema** → policy; `grantFor: null` is ungranted mode (skip grant/policy, never schema)
- [x] Validation runs on a *probe* event before a sequence number is allocated — a denied local write is a value, not a hole in your sequence
- [x] `can(schema, grant, "table.op", row)` — the same computation; `mesh.can` wraps it in E09
- [x] `claim(name).has(column)` / `.equals(column)` as the one claim primitive; `can(module, action)` is sugar for `claim("permissions.<module>").has(action)`; grants carry claims (`plan/use-cases.md` §3)
- [ ] `fields: { column: rule }` — field-level read restriction, evaluated by the relay before rows leave it (on a device it is cosmetic); taken from Instant
- [ ] Named rules by convention: `const isOwner = owner("createdBy")` reused across tables — document it, no feature needed (Instant's `bind`)

## Watch out

- Schema before policy, and schema regardless of grants. The exploration built a validator only when grants were configured, and `1.5` went into an integer column unnoticed.
- The `*any*` partition kind was overloaded with a `_policy`-specific key check; scope such checks to the table by name.
- In ungranted mode a `deny` rule is not enforced — there is nobody to deny. Document it; test it.

## Tests

- `policy.test`, `permissions.test` (every combinator, both outcomes), `validation-without-grants.test` (11 cases), `partitions.test` once E08 exists.
- `@ts-expect-error`: `owner("createdby")`, `role("nope")`.

## Done when

The same document evaluated on two engines gives the same verdict; `owner("createdby")` is a compile error; the JSON round-trip is byte-stable.
