## Goal

Sync an existing database into the mesh: the database stays authoritative, devices get a signed read-only projection, writes travel back the other way. One direction per table, never both.

## Decisions needed

D10

## Tasks

- [x] `ChangeSource` port: `start({ after }) → { changes: AsyncIterable, ack(watermark), stop }`; messages `begin / insert / update / delete / truncate / commit(watermark)`
- [x] `manualChangeSource()` first (your app calls it)
- [x] Postgres logical replication — `postgresChangeSource` in `@syncmesh/postgres`. This was ticked with the line above while only the manual source existed; it is done now:
  - [x] slot (`pgoutput`) created by a start from `null` or a first backfill and resumed after; a start from a stored watermark with no slot is `SlotLost`, never a fresh slot that skips the gap; publication created or set by `publish(tables)`; a missing publication, a foreign or lost slot, and a slot read elsewhere are each a value (`PublicationMissing`, `SlotMismatch`, `SlotLost`, `SlotBusy`); `drop()` waits for this source's streams to close
  - [x] `pgoutput` v1 decoder — Begin / Relation / Insert / Update / Delete / Truncate / Commit, Origin / Type / Message read past, every malformed frame a value; types through the relation's OIDs and their text form, identical to the backfill's `::text` read
  - [x] REPLICA IDENTITY — DEFAULT / USING INDEX key by the identity column, FULL by the primary key; a changed key is delete + insert; an unchanged TOAST value is left out of an update under DEFAULT and filled from the old row under FULL; a DEFAULT key change that did not resend a TOAST value is `PartialKeyChange`, never an insert without it; no or composite identity is `UnkeyedChange`
  - [x] standby status and keepalives — the confirmed LSN moves only past transactions decoded whole **and** acked by the bridge, or to an idle keepalive with nothing unacked; periodic status so `wal_sender_timeout` never fires
  - [x] watermark = commit end LSN as 16 hex digits, so lexicographic order is LSN order; resume skips anything at or before it
  - [x] reconnect from the last delivered transaction; a transaction cut mid-way is resent from its `begin` (now a stated port rule); backpressure pauses the socket
  - [x] slot lag alarm (`lag: { bytes, every, alarm }`) and the per-session schema alarm on a relation that changed columns
  - [x] tested on a real Postgres 17 — a `postgres:17` service in CI with `wal_level = logical`, `vp run pg:up` locally
- [x] Transaction → one signed event per partition touched; ack only after the event is durable; the watermark in a reserved `_cdc` table on **its own unpinned event, last** — not the same commit, which is where the task originally pointed. A reserved row's partition is set at fold from the event's, first-seen-wins and hashed into its digest, so riding whichever instance a transaction touched last made the row's partition a function of fold order: two peers with the same events disagreeing forever, unhealable by repair. A separate last event keeps the durability argument exactly — the position still lands strictly after every change it covers — and `UNPINNED_RESERVED` in the validator makes the pinned form impossible rather than merely absent
- [x] Backfill via a table read at a captured watermark; schema changes in the stream are an **alarm**, not an instruction; `truncate` capped

## Watch out

- Ack early and a crash loses the change with no way to re-request it — the same bug class as a transport that resolves `send` on a dropped frame.
- Ownership policy on CDC tables must read the column (`rowIs`), never the author — the authority signs everything.

## Tests

- A three-row transaction becomes exactly one event per partition; crash between event-commit and ack replays without divergence; a device write to a CDC table is denied locally and quarantined remotely.
- Postgres (`adapters/postgres/src/__tests__/replication.test.ts`): nothing is acked before the bridge acks it, and never past what was decoded; a consumer that dies mid-transaction gets the whole transaction again; a connection cut mid-transaction reconnects and resends it from its `begin`; a restart from a checkpoint neither skips nor repeats; a backfill misses no row an update moves behind the read; backfill → stream → stop → writes while stopped → restart through `startCapture` ends with the mesh equal to the table. The ack rule on its own: `acks.test.ts`. The decoder byte by byte: `pgoutput.test.ts`.

## Done when

An existing Postgres table appears on phones, offline, read-only, without being defined twice.
