## Goal

One constructor. Collections with `insert / update(draft) / delete / rows / byId / list / history`; atomic multi-collection `tx`; `can`; `revert`; capabilities surfaced from transports; reserved tables kept out of your namespace.

## Decisions needed

D02, D06, D10

## Tasks

- [ ] `createMesh({ schema, identity | peerId, account, store? | storeFor?, dataDir?, transports?, grants?, stateStore?, snapshotEvery?, undoDepth?, isAuthority?, now? })` — durable store by default
- [ ] `mesh.collections.<t>`: `insert(row)` (primary key from the row), `update(key, draft => …)` diffing to a patch and refusing an empty one, `delete`, `rows()` plain rows, `byId`, `list(opts)` returning a **descriptor**, `history(key)` ordered by stamp
- [ ] `mesh.tx(fn, { label? })` — one event, one partition; `CrossPartitionTx` refused *before* commit; `EmptyTx`; label derived from what was written
- [ ] `mesh.can`, `mesh.revert` / `canRevert`, `mesh.stop()`, `mesh.running`, `mesh.engine`
- [ ] `mesh.internal` for reserved tables; `mesh.visibility`, `mesh.blobs` (typed `NoSuchCapability` when no transport has it), `mesh.corrections`
- [ ] Every write returns `Result<SyncEvent, …>` with the full error taxonomy; no optimistic overlay

- [ ] `mesh.flush()` — settles even when some saves fail (safe to await), with a concurrency cap the docs tie to the storage's constraining resource; `mesh.stop()` = flush, then close transports and stores
- [ ] `mesh.transports.add(t)` / `.remove(name)` at construction time, not later — automerge has it from v1
- [ ] `tooling/verify-node-consumer` (moved from E00, D01 watch-out): pack each publishable package, `npm install` it into an empty Node project, `import()` it with real `node`. Bun tolerates what Node rejects (extensionless imports, `bun:*` at top level); this is the test that catches it

## Watch out

- `update` must write **only** changed columns — that diff is what makes field-level merge real.
- Reserved tables (`_policy`, `_corrections`) leaked into `mesh.collections` three times in the exploration; a test pinning the namespace caught it each time. Write that test first.
- `history()` scans the log (~63 ms at 50k events on SQLite) — a detail-view API, not a list API.
