## Goal

A document column a person can edit in a real editor: two devices typing into one note converge
through a relay or directly, edits made apart merge, cursors are shared without touching the log,
and the log stays bounded because snapshots let compaction take what they hold. Done once in
TypeScript and once in Rust, with frozen vectors keeping the two honest. RFC-0023 P3, with the
parts of P4, P5 and P7 an editor needs.

## Decisions needed

D41 (the cross-runtime contract; decided A, 2026-11-08). D38 is decided D (2026-11-08): a CRDT
in a cell is this epic's document column, not a lattice the kernel folds; its gate for Loro
(loro#1163) is met and frozen.

- [x] `@syncmesh/loro` over `loro-crdt` 1.17.1 (WASM): the `loro@1` adapter, with a canonical version encoding (D41)
- [x] `syncmesh-loro` over `loro` 1.17.1, the Rust `DocumentAdapter` trait in `syncmesh-client::docs`; Loro panics caught at the boundary
- [x] `conformance/loro-vectors.json`: replica derivation, four scripted histories (loro#1163, three-way concurrent insert, paced flushes with out-of-order apply, marks beside a map); versions byte for byte in both runtimes, snapshots and updates as documents (D41)
- [x] The runtime (`createDocuments`): `open` → the library's own document, refcounted per `(table, key, column)`; local commits paced into one doc change per burst; remote folds applied as they land; a handle invalidated on a refused flush or a moved lineage, local genesis included; a paced flush's failure reaches `onError`
- [x] Materialise: snapshot + head + `covered` in one commit (`DocStore.cover`, both SQL dialects and memory, `doc_snapshots` as its own migration step); automatic past `snapshotEvery`/`snapshotEveryBytes`; never from an open handle's unflushed state; never over a head that moved since its tail was read (`DocCoverStale`), never while ops wait on ones not held (`DocPending`)
- [x] Compaction integration: covered entries release RFC-0015's clamp; a reopen after compaction reads the snapshot
- [x] Checkpoints: produce (sign what the snapshot is) and install (producer's key, snapshot hash, adapter, winning lineage, the version re-derived from the bytes, and the tail its floor claims re-imported one update at a time without moving the snapshot; an update unreadable on its own is `failed`; one readable on its own that the snapshot refuses refuses the checkpoint)
- [x] Limits as values: a burst past `maxUpdateBytes` refused and the handle invalidated; bytes the adapter cannot read fold, then materialise as `failed` while the document stays at its last good version
- [x] `shareEphemeral`: a Loro `EphemeralStore` (loro-prosemirror's cursors) over syncmesh's presence tier
- [x] The lineage rule as RFC-0023 §16.1 decided it (2026-11-08): first genesis wins, as a tree — a genesis names the lineage it replaces (`parent`, data key 6), the cell holds the set of geneses, the walk picks the winner; permutation tests and `doc-vectors.json` lineage trees in both runtimes; genesis key 5 is `1`, so an older build refuses it
- [x] `allow.replace` (§16.2): optional, defaulting to the row's `update` rule, enforced by the shared validator
- [x] Row revert compensates only cells that still hold the write's stamp (§16.3), `skipped: superseded` reported; Rust `Engine::revert` / `Mesh::revert` with the same rule
- [x] Derived columns (RFC-0023 §16.4, decided 2026-11-08): `drizzleTable(t, { merge, derive: { title: from("content", …) } })`, computed by every replica after each flush (in the flush's transaction, so a live query reads it with the edit) and each materialisation or checkpoint install (with the cover); written to the app's row only, never a cell, a change or a digest input; refused as this device's own write (`DocColumnWrite`) by the validator and capture, while a numbered event naming one (history from before the derive, or an older build) still folds with the cell ignored; an opaque host writes a device checkpoint's key 8 (`installProvisional`), empty for a sealed partition; Rust `Derive` builder over the manifest's names
- [x] Derived-column follow-ups (gaps U22 in part, U25–U28, decided 2026-11-08, Jace delegated the call): the runtime recomputes a row's derived columns when the fold moves its document (a remote edit to an open or closed document, a `replace()`, a lineage move), when its row appears (a late insert, a delete and re-insert), when a snapshot, a repair or a D45 purge rewrites it, and once per row at start (a rebuilt state file, a changed derive function), guarded by `engine.writeDerived`; `documents.rederive()` asks for it; `installProvisional` takes a checkpoint only from the authority or a producer the row's `update` rule admits (`engine.mayEditDoc`); a write rule reading a derived column is refused at schema construction; the Rust validator refuses a local write naming a derived column (`EngineOptions.derived`); CDC's `meshCells` leaves derived and document columns out; unreadable state holding snapshot-installed rows is refused rather than rebuilt without them where its cursors can be read, and since gaps U33 (#34) wherever the log records the install's floor, which it now always does; a D45 purge invalidates a replica open on a row it rewrites; a recomputation reads an open replica only while it holds nothing uncommitted, so a refused flush leaves nothing of its edits on the row
- [x] The lineage cell carries its rule's version (`[1, { lineage → genesis }]`) in snapshot pages, repairs and persisted state; a cell of another version is refused as `LineageCellRefused`, never read as the root (§16.1); `doc-vectors.json` `lineageCells` in both runtimes
- [x] A parent that lands in a snapshot page or repair record relabels the doc log and head at once, not at the next append (§5.3)
- [x] The Rust adapter's `snapshot()` returns an export failure as `UpdateRejected` (D41)
- [x] `allow.replace` in Rust, with the whole policy ladder (U3; RFC-0023 §11 says why not alone): `syncmesh_client::validate` over `portableSchema`'s manifest, verdicts frozen in `conformance/policy-vectors.json`
- [ ] DocCheckpoints riding RFC-0019 snapshot pages, so a late joiner is handed one by the transport rather than by the app (P5)
- [ ] Blob-carried updates past 64 KiB (D18) instead of refusing them
- [ ] React Native: `@syncmesh/loro/native` over `loro-react-native` (≥1.17) or UniFFI over `syncmesh-loro` (D41, D35 slice 5)
- [ ] `ctx.docs.change` inside a mutation, `DocRef` in query-side tables, `useDoc` (P4)
- [ ] Doc compensation for `$actions.undo` (P6)

## Watch out

- Two editors seeding an empty document concurrently create two roots; the author lays it out once (D41).
- Snapshot bytes are not canonical, even within one runtime: compare versions, never snapshots.

## Done when
