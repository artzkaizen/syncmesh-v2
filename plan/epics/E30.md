## Goal

A document column a person can edit in a real editor: two devices typing into one note converge
through a relay or directly, edits made apart merge, cursors are shared without touching the log,
and the log stays bounded because snapshots let compaction take what they hold. Done once in
TypeScript and once in Rust, with frozen vectors keeping the two honest. RFC-0023 P3, with the
parts of P4, P5 and P7 an editor needs.

## Decisions needed

D41 (the cross-runtime contract; decided A, 2026-11-08). D38 is decided D (2026-11-08): a CRDT
in a cell is this epic's document column, not a lattice the kernel folds; its gate for Loro
(loro#1163) is met and frozen.

The join exchange takes `SnapshotDocs` (`documents.pages(identity)`, which a mesh with `documents` hands every link): the joiner installs the checkpoints after the rows and, below a peer's floor, adopts the coverage only once every page was complete and every checkpoint's floor is held, lifting D46's doc-column refusal. A page spends at most half a frame on checkpoints; the rest are left out and the page marked incomplete. A sender without a document runtime sends version 1 unchanged; `snapshot-vectors.json` gains `served.documented`. The joiner checks a page's `complete` rather than take it: a row whose cell names a lineage with no checkpoint on the pages earns no floor (fix round 1); a document never replaced leaves no lineage in its row, so for it the sender's word still stands; a checkpoint whose producer may not edit its row is not installed and earns no floor, and since one such checkpoint makes the install answer `false` for the whole snapshot, a joiner takes **no** floor from a peer that may not edit some documented row of what it serves (a read-only member, a row under an owner-only `update` rule, a relay that is not the authority): it gets the rows and the documents it may trust, and catches up on the rest from the log; a page sheds checkpoints from its end until the encoded page fits a frame beside large rows; a sender whose document runtime throws while serving still sends its pages, with no checkpoints and marked incomplete, so the joiner's exchange closes (fix round 2); a document runtime that rejects on either side is reported to `JoinDeps.onError` as `SnapshotDocsFailed` (`step` `serve` or `install`; a session's `BridgeError`), and a joiner whose install rejects still settles, adopting no floor (fix round 3). Departs: no page-version negotiation; the page budget assumes the default frame (`DEFAULT_MAX_FRAME_BYTES`), so a link configured with a smaller `maxFrameBytes` can still be handed a page past it, as can a page of rows alone past a frame (both as before P5); so an older build loops asking for a documented page it cannot read (accepted before 1.0); a snapshot request materialises and signs a checkpoint per document, uncached; inline bytes rather than a blob ref on the bulk profile; the Rust device reads version 2 pages but, with no document runtime (P7), installs no checkpoint and still adopts nothing below a floor on a schema with documents

## Still open, decided (2026-11-08, Jace delegated the call)

The five open boxes above are wanted, and each is its own PR after #39 rather than a fix round
of it, in this order:

1. **The snapshot written into the column (§6.1)** first: it needs the materialiser to write the
   app's column with capture disarmed on both SQL dialects and the Postgres driver suite, and
   P5 hands joiners what it writes.
2. **P5, checkpoints in RFC-0019 snapshot pages:** a page format change in both runtimes and the
   frozen page vectors, so it lands with its own conformance vectors.
3. **P6, doc compensation for undo:** a new SPI member (a compensating update from the action's
   own updates), built over `oplog@1` and Loro with the conformance suite extended; until then a
   revert of a document-only write stays refused, as §9 says.
4. **P7, cross-runtime live interop:** needs a Rust document runtime (open, apply, materialise,
   blob fetch) over `syncmesh-loro`; Rust blob-carried updates land with it.
5. **React Native** last: `loro-react-native` or UniFFI over `syncmesh-loro`, after P7 gives the
   Rust runtime it would bind.

Built 2026-11-09 (Jace delegated the call), as one PR rather than one per box: 1, 2 and 3 above.
Still open: 4 (P7) and 5 (React Native), with what blocks each on its box.

## Watch out

- Two editors seeding an empty document concurrently create two roots; the author lays it out once (D41).
- Snapshot bytes are not canonical, even within one runtime: compare versions, never snapshots.
