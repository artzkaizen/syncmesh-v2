## Goal

Store-and-forward of signed bytes by a process that holds no keys: rooms, per-author cursors, paged catch-up with grants first, durability acks with log offsets, backpressure that never drops and never grows, a durable room log, and a host-agnostic core that runs under Bun, a Durable Object, or an actor.

## Decisions needed

D09 topology · D14 handshake versioning

## Tasks

- [ ] `RelayRoom({ name, store, keepaliveMs?, fanout? })` over an `EventStore` and a `RelaySocket { send, close? }`
- [ ] `join` → `hello { v, keepalive, epoch }` + paged catch-up (2,000/frame, grants in page one, `more`, offset `o`) + the relay's own cursors
- [ ] `ka` keepalive on cadence; `epoch` persisted with the log (lineage id)
- [ ] `ingest`: decode enough to dedup by `peer-seq`, append, `ack { id, o }` to the author, `event { w, o }` to everyone else
- [ ] Grants store-and-forward by bytes; `blob-put` verify-on-put / `blob-get` / `blob-missing`
- [ ] `sendOrQueue` + `drain` — `ws.send()` returning 0 means *not sent*; per-socket backlog; at the ceiling, **close**
- [ ] `startRelay(port, { store?, dataDir?, fanout?, keepaliveMs? })` — durable by default under `.syncmesh/relay/`
- [ ] `Fanout` port; `memoryFanout()`; `redisFanout({ client })` with a structural client — best-effort, cursors recover what it misses
- [ ] Client `RelayTransport`: join with cursors; apply pages strictly in order in time slices; **push-outstanding after the last page**; keepalive deadline at 2.5× re-armed on every frame (a hello-less relay arms nothing); reconnect backoff; `token()` / `visibleAt()` with `VisibilityLost` on lineage change; `putBlob` / `fetchBlob` verified
- [ ] `Relay` transport class declaring `visibility` and `blobs`

- [ ] Handshake versioning from day one: `join { supportedProtocolVersions }` → `hello { selectedProtocolVersion, keepalive, epoch }` | `error` then close (D14)
- [ ] A second `join` from the same peer id disconnects the old socket **first** — never two sockets for one peer, never a silent room switch
- [ ] Persist what each remote peer had, keyed by the thing that persists (device key), not the connection — a re-meeting skips the round trip
- [ ] The relay forwards grants first and byte-identical (`wireFor`), never re-encoded (E07 task 4)

## Watch out

- Every raw `ws.send` is a future hang. The 100k-event load rig found a joiner that received exactly the buffer's worth and hung forever.
- A dropped row patch (E13) is unrecoverable — always queue it.
- The first `join` binds a socket to a room; a second must not silently switch rooms and leak the socket.
- The relay is in memory until E04 lands — do not ship it that way.

## Tests

- `relay.test`, `relay-room.test` (restart over the same file keeps events and epoch; fanout across two rooms; a fanout that drops everything is recovered by cursors), `catchup-paging.test` (progress survives a crash mid-join), `liveness.test` (mute-but-open socket dropped and retried; hello-less relay left alone), `visibility.test` (lineage change while a waiter is pending settles Lost), `blobs.test`, `grant-exchange.test`, `spike-ingest.test`, `scale.test`, `fuzz-and-load.test` (load half).

## Done when
