## Goal

A peer with three extras — always on, holds the whole log, its grant carries authority — that can publish permissions by sync, overrule with a reason instead of rejecting, and detect and heal divergence.

## Decisions needed

D10

## Tasks

- [x] `setPolicy(engine, partition, doc)` — the rules as data in a `_policy` row keyed by, and living in, the instance they govern, so a doc travels to exactly the devices it binds; `syncedRules` in the validator prefers it over the bundled manifest per table, caching the parse per record. Only the configured authority peer may write it, checked by authorship, so a device cannot loosen the rules that bind it
- [x] `correct(engine, { event, table, key, reason, detail, partition }, fix)` — the fix and its reason in **one** signed event, so no peer can fold the overwrite without the reason; `_corrections` is authority-only by the same rung as `_policy`; `mesh.corrections.{all, mine, forEvent}` reads them, with `mine` keyed off the event id's own author prefix
- [x] Digests: `engine.digest()` (per table) and `rowDigests(table)` as a **sum** mod 2^64 of each row's sha-256 over its canonical record encoding — a sum, never an XOR, so a row present twice cannot digest as its own absence; `divergentTables` / `divergentRows` narrow table-then-row; `rowRecords` hands them over and `repairRows` merges them with the ordinary field-level merge, commutative in both directions and adopting **no** cursors. The record codec moved to `@syncmesh/wire` (where the other codecs live) so the engine and the stores share one canonical encoding, with `hlcOf` to the kernel beside `Hlc`
- [ ] Digests on the last catch-up frame, carrying their interest so cross-scope mismatches do not false-alarm — **blocked on E13's `Interest`**, not on an IVM: two peers that hold different slices must compare like for like or every catch-up looks like divergence

## Watch out

- The authority cannot *reject*: an unreachable peer keeps the provisional value with nothing ever contradicting it. Rejection is an overwrite with a reason.
- An absent table and an empty one must digest identically.
- A mismatch in a mixed-version fleet is ambiguous (RFC-0013 G18).

## Tests

- [x] `authority.test`: a synced doc tightens and loosens the bundled rule for its own instance and no other; a device's forged doc and forged correction are both refused at their own author (so nothing reaches a peer to be re-checked), and the refused correction's fix never applies either; the fix and its reason are one event.
- [x] `digest.test`: order-free summation; an absent table and an empty one are the same fact; a duplicated row changes the digest (what an XOR would hide); divergence narrows table-then-row; symmetric repair heals both ways adopting no cursors; a repair notifies live queries once with the keys it touched, and healing nothing is not an event.

## Done when

Permission changes deploy by sync with no app release; two deliberately diverged peers heal on next catch-up.
