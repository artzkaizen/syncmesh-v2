## Goal

Cursors, typing, who-is-here: a tier that never touches the log, the snapshot or the compaction floor, conflated at every hop so a stalled socket gets the current value and never a backlog.

## Decisions needed

D16

## Tasks

- [ ] A presence wire kind; signed; never appended, never snapshotted, never counted
- [ ] Conflation at sender, relay (last value per room/key/peer) and receiver
- [ ] TTL expiry **and** explicit clear; keyed `(account, peerId)`
- [ ] `presence:` block in the manifest; `mesh.presence.<k>.set / clear / peers()`; a React hook

- [ ] `(sessionId, count)` on every ephemeral frame — session random per process start, count monotonic — and a bounded seen-set, so gossiping presence across a mesh cannot loop

## Watch out

- Keying by connection instead of account is reflectdb's documented wart.

## Tests

- A 60 Hz burst leaves log, snapshot and compaction floor byte-identical; a late joiner sees current presence and no history; a stalled socket receives the latest value, never a backlog.

## Done when

Live cursors in the demo at pointer rate with the event log untouched.
