## Goal

Cursors, typing, who-is-here: a tier that never touches the log, the snapshot or the compaction floor, conflated at every hop so a stalled socket gets the current value and never a backlog.

## Decisions needed

D16

## Tasks

- [x] A presence wire kind: its own signed core (`v, peerId, topic, partition, session, count, value, expires`) in `@syncmesh/wire`, frame tag 4 alongside grants and cursors, and nothing else in common with an event — never appended, never folded, never snapshotted, never counted by a cursor, never in catch-up. The engine does not know the tier exists
- [x] Conflation at all three hops, by one shared `createPresenceStore`: last value per `(topic, instance, peer)` at the sender, in the relay room, and at the receiver. Nothing queues, so a stalled socket gets the current cursor rather than a backlog
- [x] TTL expiry **and** explicit `clear()`; `stop()` is a departure, so a closing tab vanishes now rather than at TTL. A heartbeat at a third of the TTL keeps a still-present peer alive
- [x] Identity is `(account, peerId)` — resolved through grants at read time, so a value that outran its author's grant is not stranded anonymous
- [x] `presence:` block in the manifest (`{ partition, of, ttlMs? }`, validated at definition like a table); `mesh.presence("board:b1").cursor.set / clear / peers / subscribe`, typed from the manifest; `usePresence` in `@syncmesh/react`, identity-stable so an unchanged set costs no render
- [x] `(session, count)` on every frame — session random per process start, count monotonic — with a bounded seen-set (1,000 sessions) at every hop, so a gossip echo dies where it lands

## Watch out

- Keying by connection instead of account is reflectdb's documented wart.

## Tests

- [x] `client/presence.test`: a value crosses with its account and the log stays empty (no events, no state); twenty sets conflate to one value; topics and instances stay separate; `clear` removes it now and a stale value expires on a moved clock; `stop()` is a departure; a bad value is a definition mistake.
- [x] `relay/room.test`: a value forwards byte-identical, is never echoed to its author, a repeated count stops at the hop, and a joiner is told who is here — with no history, because there is none.
- [x] `react/hooks.test`: `usePresence` renders the set, once per change, and not at all when the set is unchanged.
- [ ] The 60 Hz burst as a load test, and a BLE-shaped drop test (RFC-0015's route scorer sheds ephemeral traffic first).

## Done when

Live cursors in the demo at pointer rate with the event log untouched.
