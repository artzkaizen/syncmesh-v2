## Goal

The surface an app author writes: column kinds with runtime validation, tables with inferred row types, one manifest for partitions/roles/tables, conflict rules on the column, and a way to import tables from Drizzle so nothing is defined twice.

## Decisions needed

D06 contract shape · D04 (strategies on columns)

## Tasks

- [x] `t.text/integer/float/boolean/timestamp/json/blob/uuid` with the exact accept/reject table (`uuid` refuses non-canonical, never normalises)
- [x] Modifiers: `primaryKey nullable unique default check(schema) onConflict(strategy)` — `onConflict` typed by value (`StrategyFor<T>`) so `t.text().onConflict("max")` is a compile error
- [x] `t.json(schema)` inferring `T`; Standard Schema declared structurally (zod/valibot/arktype, no deps); synchronous only, purity documented
- [x] `checkValue` (`checkRow` arrives with `table`) returning `Result`; kind check before schema check; `.nullable()` owns `null`
- [x] `table(name, columns)` → `{ name, columns, primaryKey }`; 0 or 2 primary keys throws at module load; `Row` / `InsertRow`
- [x] `defineSchema({ partitions, roles, tables })` — one argument; per table `columns | table`, `partition` typed against the manifest, `allow` (E06 adds the slot and combinators), a Drizzle table accepted directly (conflict rules via `fromDrizzle(t, { onConflict })`, typed against its columns — no untyped `merge` map); exhaustive both ways; produces `entries`, `policy`, `merge: MergeSpec`, `rolesFor`
- [x] Reserved tables installed by the manifest (`_policy`, `_corrections`) kept out of the app namespace
- [x] `fromDrizzle(table, { onWarn })` — keyed off semantic `dataType` as base + qualifier; refuse serial/generated/unbounded numeric/no single PK; warn on unique/computed defaults/Date columns; row types from Drizzle's inference

## Watch out

- Drizzle's `columnType` differs between builds of the same installed version; a mapping that determines wire bytes cannot rest on it. Use `dataType` — and read `"string date"` (ISO text) and `"object date"` (a Date) differently.
- The type mapping is a frozen artifact: changing it invalidates every existing log.
- `t.json<T>()` with no schema accepts anything at runtime. Make the schema form the one people reach for.
