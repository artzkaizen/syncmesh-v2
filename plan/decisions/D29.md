## Context

The codebase has 138 `class` declarations and, with one exception, every one of them is a
`TaggedError("Tag")<{ … }>` subclass. Behaviour is built the other way: 94 exported factories
named `createX` / `openX` take a `deps` struct, hold their state in `let` bindings, and return an
object literal typed against an interface whose members are function-valued properties —
`readonly record: (op) => Promise<Result<void, StoreFailure>>`, not a method signature. The
exception is `Writer` in `wire/src/cbor.ts`: module-private, not exported, a mutable byte
accumulator with small methods over it.

None of that was written down. The only trace is a doc comment in `client/src/telemetry.ts`,
and the reason it needed writing down is that the choice is **load-bearing at runtime**, not a
style. Four places in production build a seam value by spreading another one and replacing the
members they mean to change:

- `client/src/telemetry.ts:94` — `{ ...transport, start }`, then `Object.assign` for each
  optional capability the wrapped transport happens to have;
- `client/src/operations.ts:143` — `{ ...store, record }`;
- `client/src/inspect.ts:98` — `{ ...handle, … }`;
- `ble/src/transport.ts:501` — the BLE transport *is* `{ ...createFrameTransport(…), reaches,
  maxLinks, drop, wake }`.

`{ ...instance }` copies own enumerable properties and nothing else. A prototype method is not
one. So a factory that started returning a class instance would make every one of those wrappers
produce an object with `start` and none of `send`, `onFrame`, `stop` — silently, because the type
would still say `Transport` and nothing checks a seam's shape. The telemetry comment names this
failure exactly and rejects the alternative, a wrapper that lists the members it knows: that one
drops each new member as the interface grows, which is D17's silent-gap objection in another form.

The second thing spreading depends on is that an optional member is **absent**, not present and
inert. `withBlobs()` reads `blobs !== undefined`; settling reads `caughtUp !== undefined`. A
class either declares a method or does not; conditional absence means assigning it in the
constructor, which is object assembly with a longer route.

Against that, the closure pattern has a real cost where state is heavy. `relay/src/transport.ts`
held fourteen `let` bindings in one factory, with no single place a reader could see the object's
state, and a wrapper at line 82 — `createBlobChannel((frame) => sendSafe(frame))` — that existed
only because `sendSafe` was a `const` declared thirty lines below and could not be referenced
yet. That is a class's job being done with worse tools. It was the only file in that shape:
`ble/src/transport.ts` already decomposes through `createFrameTransport`, the browser
`host-handle.ts` factories hold four and two fields, and `drizzle/src/live.ts`'s bindings are
per-query locals rather than object state.

## Options

- **A · Classes for behaviour.** `class RelayTransport implements Transport`, exported, and the
  same for stores and drivers. Rejected: breaks the four spread sites above without a type error,
  and makes optional capabilities a constructor-time `Object.assign` anyway. D12 considered a base
  class for transports ("most transports extend a base class and write ~20 lines") and the same
  objection applies with more force — a base class would put the adapters' dependency arrow
  backwards, into the package that declares the interface they implement.
- **B · Closures everywhere, no exceptions.** Today's practice, made a rule. Rejected: the relay
  transport is what it costs. Fourteen fields that cannot be read in one place, a forward
  reference that needs a wrapper to exist, and a debugger that shows closure scope where it would
  show `this`.
- **C · Two tools, and a line between them.** A class for nominal identity — a `TaggedError` that
  must revive across a wire by its tag, `instanceof`, and a stack — and for **module-private
  state**: a non-exported class holding the fields, with the exported factory returning the object
  literal it always returned, each member delegating to the instance. Nothing typed as a seam
  interface is ever a class instance.

## Decision

**C.** The invariant, precisely: **a value typed as a seam interface — `Transport`, `SqlDriver`,
`OperationStore`, `EventStore`, any interface a wrapper might spread — has every member as an own
enumerable property.** Factories return object literals. Classes are not exported, and do not
appear in a `.d.ts`.

1. **The invariant is asserted, not described.** `spreadable(value, label)` in
   `engine/src/suite.ts` walks the prototype chain and names every member a `{ ...value }` would
   drop. The transport contract runs it over every transport a `Connect` builds — which is why
   `SuiteNetwork` now carries `transports`, required rather than optional, so a medium cannot
   forget to hand them over — and the driver contract runs it over every driver it opens. A new
   adapter inherits the check by running the suite it already has to run.

2. **The relay transport is the precedent for the private class**, and the shape to copy. A
   non-exported `RelayLink` declares the fourteen fields once, holds the methods that read them,
   and `relayTransport()` keeps its signature and returns the literal. The TDZ wrapper is gone.
   Doc comments moved with the behaviour they describe; the literal is a table of delegations.

3. **The threshold is the reader's, not a number.** A factory earns a private class when its
   state can no longer be read in one place, or when a forward reference needs a wrapper to
   exist. Two or four fields do not; `cbor.ts`'s `Writer` and the relay transport do.

## What this costs, accepted

- **A delegation layer** on every seam a private class sits behind: one arrow per member,
  `start: (ctx) => link.start(ctx)`. Twenty lines on the relay. The alternative — returning the
  instance — is the failure this record exists to prevent.
- **A required field on `SuiteNetwork`**, which every `Connect` in the tree had to add. Five
  sites, one line each, and the reason it is required rather than optional: a shape check that
  skips when the shape is unavailable is a check that skips exactly when it would have fired.
- **Two ways to hold state**, and a reader has to know the line. The line is the export: if it
  crosses one, it is a literal.

## Watch out

- **A lint rule cannot enforce this.** Oxlint's JS plugins see an untyped AST; a rule cannot tell
  a seam factory from any other function, or a returned identifier from a class instance. The
  suite can, because it holds the value. Do not spend time on the rule.
- **`Object.freeze` and getters are the same hole.** A getter is an own property but a spread
  copies its *value* at that moment, not the accessor; a frozen literal is fine to spread but the
  copy is not frozen. Neither is in use on a seam; if one arrives, `spreadable` will not see it.
- **The delegation must not be `link.start.bind(link)` for every member.** `bind` produces a
  function that is an own property — it passes the check — but it is the same allocation the
  closure pattern made, per member per instance, with `this` threaded through. The arrow reads
  as what it is: a table of which method answers which member.
- **Do not let the private class leak through a return type.** `relayTransport(): Transport`,
  never `: RelayLink`. Inference will happily widen a `return link` to the class, and from there it
  is one refactor from the `.d.ts`.
